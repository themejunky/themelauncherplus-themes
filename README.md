# Theme Launcher Plus — theme catalog

Public theme catalog and content-addressed theme packages for the Theme Launcher Plus Android app, served by GitHub Pages:

- `v1/catalog.json` — the catalog (format: theme-launcher-plus repo, `docs/THEME_FORMAT.md`)
- `v1/themes/<id>/{thumb,preview,package}/<sha256>.<ext>` — immutable files

Generated by `tools/themes/build_themes.py`; never edit by hand. Old files are not deleted in the publish that stops referencing them.
